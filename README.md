# IntentTrace: Checkpoint 1

**Status:** evaluation set designed; neither approach has been run.

This folder freezes four synthetic workflow cases before implementation: intent/constraint, failed import and recovery, correction handling, and insufficient evidence. Each case includes a transcript, planned visual beats, expected outcome, pass/fail checks, and claims that must not be invented.

## Files
- `evaluation_set.json`: machine-readable workflow inputs and expected outcomes.
- `scoring_rubric.md`: scoring rules.
- `scorecard.csv`: blank manual scorecard for later baseline and intent-aware outputs.

## Integrity rule
Do not edit the expected outcomes after seeing either approach's output. If a genuine ambiguity is found, record it separately before scoring both outputs. These are synthetic cases, not real-world validation.
